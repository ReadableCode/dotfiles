# Setting up Git portable

## Install portable git

- Download and extract portable version from [Git for Windows Portable](https://git-scm.com/downloads/win)
  to `%USERPROFILE%\userapps\PortableGit\` — that exact folder name is what the
  shared PATH block expects, see
  [setup_windows_portable_userapps.md](./setup_windows_portable_userapps.md)
